* To log in to **Mobilizon**, all users (including the administrator) must first be logged out of the user portal, or SSO. 
* To log in with the **Mobilizon** administrator, use the email address and password of the user chosen during installation, you will be prompted to create a new profile the first time you log in. 
* By default, registrations are closed. 
* All YunoHost users are allowed to log in with their email address and password and will be prompted to create a new profile the first time they log in.
